# 鸿蒙版安装与更新指南

> 适用于华为 HarmonyOS（鸿蒙）手机 / 鸿蒙电脑。安卓、iOS、Windows、macOS、Linux 用户不用看这份，直接下对应安装包即可。

## 一句话说清为什么这么麻烦

鸿蒙系统只允许安装**带签名**的应用（相当于应用要有系统认的"身份证"）。NexHub 发布的是**未签名包**，签名这一步由你在自己的手机或电脑上完成——用你自己的华为开发者账号签一次，系统就认了。

所以只有两条路：

| 你的情况 | 该走哪条 |
| --- | --- |
| 想以后在手机上直接更新，不想每次连电脑 | **方式一**：装一次「轻启·安装器」，之后全在手机里搞定（推荐） |
| 只想装一次 NexHub，不想多装一个安装器 | **方式二**：用电脑上的工具签一次名装进去 |
| 手边没有数据线 | **方式三**：无线安装 |

## 装之前先看清三件事

1. **文件对不对**：`NexHub-ohos-arm64-unsigned.hap`（约 99 MB）。带 `unsigned` 是正常的，不是残缺包。
2. **要不要华为账号**：要。签名必须用**华为开发者账号**（免费注册，需要实名认证）。这不是 NexHub 的额外要求，是鸿蒙系统的规则。
3. **数据会不会丢**：升级是覆盖安装，插件、书架、收藏、播放记录都保留。只有**卸载**才会清数据。

**设备要求**：只提供 arm64 版本；构建基线是 HarmonyOS SDK 26.0.0，系统太旧会装不上或装完打不开。官方声明支持鸿蒙手机与鸿蒙电脑（2in1），平板未单独适配。

## 方式一：装「轻启·安装器」，以后在手机上更新（推荐）

这条路只有第一次需要电脑，之后安装、更新、换新版本都在手机里完成。

### 第 1 步：电脑上准备两个文件

- **轻启·安装器**：打开 `https://github.com/thx853068675-dev/QSStore/releases`，下载最新的 `quietstart-installer-xxx-unsigned.hap`。
- **签名工具**（任选一个，都能自动帮你签名）：
  - 小白调试助手：`https://github.com/likuai2010/auto-installer/releases`（Windows / macOS / Linux 都有；Windows 第一次打开会提示装 Java，按提示装即可）
  - HoKit：`https://github.com/yabi-zzh/HoKit/releases`

### 第 2 步：手机上打开开发者模式

1. 设置 → 找到「设备型号」（部分机型写作「关于本机」）
2. **连续点击「软件版本」7 次**，直到提示"开启开发者选项"
3. 点确认，手机会自动重启
4. 重启后：设置 → **系统** → **开发者选项** → 打开「USB 调试」

### 第 3 步：把手机连到电脑

用数据线连接（**必须是能传数据的线**，纯充电线不认）。手机弹窗"是否允许调试"→ 点**允许/信任**。

> 工具里能看到设备名称，就说明连上了。

### 第 4 步：把轻启装进手机

在工具里选择刚才下载的 `quietstart-installer-xxx-unsigned.hap` → 点安装。工具会引导你**登录华为账号**，用你的账号生成签名再装进去。第一次会花一两分钟，属正常。

### 第 5 步：在轻启里装 NexHub

1. 手机打开「轻启·安装器」
2. 按提示**登录华为开发者账号并授权**（轻启需要它在本机申请调试证书、登记这台设备）
3. 搜索 `NexHub` → 点安装

装完后，NexHub 就是普通应用，桌面图标、通知、后台都正常。

### 以后怎么更新

- 打开轻启 → 「我的关注」或已安装列表里会显示新版本 → 点更新即可。
- 也可以在轻启里对 NexHub 点关注，有新版本会收到通知。
- 更新是覆盖安装，数据不动。

## 方式二：只用电脑装 NexHub，不装安装器

1. 手机按「方式一 第 2 步」开好开发者模式和 USB 调试
2. 电脑上打开 `https://github.com/nexhub-app/NexHub/releases`，下载 `NexHub-ohos-arm64-unsigned.hap`
3. 数据线连电脑 → 手机点允许调试
4. 用签名工具（小白调试助手 / HoKit）选这个 HAP → 登录华为账号 → 安装

**以后更新**：回到 Release 页下载新 HAP，重复第 3、4 步。也是覆盖安装，数据保留。

> 也可以不用第三方工具：装了 DevEco Studio 的话，用它的自动签名 + `hdc install` 命令同样能装（适合开发者）。

---

## 方式三：无线安装（没有数据线）

1. 手机和电脑连**同一个 WiFi**
2. 手机：设置 → 系统 → 开发者选项 → 打开「无线调试」，记下显示的一串 `IP:端口`
3. 在签名工具里选"无线连接"，填这串地址；首次连接手机上会弹授权，点允许
4. 之后选 HAP 安装即可，步骤同方式二

轻启还支持**局域网批量安装**：同一 WiFi 下，一台手机给多台鸿蒙设备装同一个应用（对方需要开着调试）。

## 更新这件事，别被绕晕

| 场景 | 正确做法 | 数据 |
| --- | --- | --- |
| 装了轻启 | 轻启里点更新 | 保留 |
| 没装轻启 | 重新下载新 HAP 覆盖装 | 保留 |
| 应用内点「检查更新」 | 会打开浏览器到发布页，需手动下载 | 保留 |
| 想装回旧版本 | 先卸载再装旧包 | **丢失**（先做备份） |

鸿蒙不允许应用自己静默安装新版本，所以 NexHub 内的「检查更新」只能把你带到下载页，这一步必须由你手动完成——这是系统限制，不是功能缺失。

## 常见问题

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 提示签名不一致 / 安装校验失败 | 手机里已装的那份是用**另一张证书**签的（换过华为账号、或旧证书被废除） | 卸载后重装。卸载会清数据，先在应用内做一次备份 |
| 提示"应用已过期" / 打开被拦截 | 调试证书到期了（实名账号通常一年，未实名只有两周左右） | 在轻启里对该应用做一次"续期/重签"，或重新走方式二装一遍 |
| 工具里看不到手机 | 线只充电、没开 USB 调试、没点"允许"、或当前在子用户 / 隐私空间 | 换数据线、开 USB 调试、点允许、切回机主空间 |
| 登录华为账号报 403 / 权限不足 | 账号没实名、或没有调试类证书权限 | 先在华为开发者联盟完成实名认证，再重试 |
| 装完打不开 / 闪退 | 系统版本低于构建基线 | 升级系统；或换一台新系统设备 |
| 提示"降级" | 装的版本比手机里已装的低 | 装更新的版本，或先卸载 |
| 应用市场里搜不到 NexHub | 没有上架华为应用市场，只在发布页分发 | 按本文方式安装，属正常 |
| 平板能装吗 | 未单独适配平板 | 能装上但不保证布局，建议用手机或鸿蒙电脑 |

## 安全提醒

- **只从官方 Release 页下载**。第三方网盘、群文件的"魔改版"可能被换过内容。
- 签名用的是**你自己的**证书，所以签完名的文件和官方发布的文件**内容一样、签名不同**，这是正常现象。
- 不放心的话，下载后核对文件大小与官方 Release 页显示的一致（约 99 MB）。
- 任何工具要你上传账号密码到陌生网站，都不要给。正规工具是在本机完成签名，只走华为官方登录页。

---

## 卸载与回退

- 卸载：桌面长按 NexHub 图标 → 卸载。**会清空应用数据**。
- 想保留数据又必须重装：先在应用内 设置 → 备份与恢复 导出备份，装好后重新导入。
- 想回到旧版本：只能卸载后装旧包，数据需从备份恢复。

## 附：给维护者（发版必查三条）

1. `ohos/AppScope/app.json5` 的 `versionCode` **必须递增**，否则安装器识别不到更新（用户会一直显示"已是最新"）。
2. Release 资产名保持 `NexHub-ohos-arm64-unsigned.hap`、以 `.hap` 结尾。
3. beta 版本记得标 prerelease，避免被当作正式更新推给所有人。

渠道与上架细节见 `docs/OHOS_INSTALL_UPDATE_PLAN.md`。
